# CoreRef

Фреймворк для аппаратных маршрутов на Nix. Flow связывает стадии обычными функциями Nix и
реализует сами преобразования на Python. Проект подключает Flow как flake input и
выставляет выбранные результаты в `packages`. Команда `nix build .#netlist`
собирает только необходимые стадии или получает результаты из бинарного кэша.

Python API `Project` даёт CLI-командам доступ к этим целям, закреплённым
зависимостям и локальным checkout.
