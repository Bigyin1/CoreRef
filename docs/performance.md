# Пакетное получение файлов и исходников

Замеры от 2026-11-06: Python 3.15, Conan 2.34.x, macOS arm64, собственный локальный
Conan-сервер и временный cache. Медианы трёх прогонов после прогрева. Синтетический
RTL-пакет содержит один SV-файл; setup, публикация, первый Git clone и запуск
CLI-процесса исключены. Simulate здесь означает подготовку входов и preview, без EDA.

| Сценарий | До, мс | После, мс | Команд Conan API до → после |
|---|---:|---:|---:|
| Simulate, цепочка 12 зависимостей | 895.946 | 135.786 | 283 → 38 |
| Исходники после resolve, та же цепочка | 788.592 | 23.016 | 246 → 1 |
| Simulate, 12 независимых зависимостей | 408.591 | 149.903 | 85 → 38 |

До оптимизации каждый Ref.get_with_sources() заново получал метаданные closure
и выполнял отдельный install. Для цепочки из N пакетов происходило N(N+1)/2
повторных чтений метаданных на стадии получения исходников.

Simulate передаёт всё дерево зависимостей локального проекта одной группой.
Общие узлы не дублируются; корень читается из рабочего дерева и не требует публикации.

Flow теперь передаёт выбранные Ref в Graph.get_with_sources(refs). SDK использует
уже проверенные StoredRecipe, формирует один consumer выбранных пакетов и выполняет
один install. При Genus SCM включается только для пакетов, исходники которых нужны
после отсечения ветвей. Conan по-прежнему может установить их бинарные зависимости.
Graph.get(refs) использует ту же общую установку для файлов без запроса SCM;
содержимое payload уже прочитано при разрешении графа.

Временный lockfile создаётся штатным LockfileAPI из сохранённого нативного графа.
Проектный lockfile не перечитывается; все транзитивные revisions остаются закреплены,
включая зависимости внешних рецептов без явно записанного revision. После установки
SDK проверяет, что выбранные ссылки присутствуют и все зависимости принадлежат снимку.

Graph хранит успешные результаты получения до конца своей жизни. Повторный запрос
той же записи не запускает Conan; для новых Ref выполняется следующая общая установка.
Переход от файлов к исходникам требует ещё одной установки для выбранных записей;
последующий get() использует готовую запись с source.
Ошибка не добавляет частичные записи в этот кэш. Conan может сохранить частично
полученные файлы в собственном cache и использовать их при повторной попытке.

Регрессионные проверки покрывают холодный reader cache через сервер, пакетные файлы,
Git SCM, исключённый недоступный Git-исходник в транзитивной зависимости выбранного
родителя, удалённый проектный lockfile, изменение опубликованного revision после
resolve, повторные обращения и повтор после сбоя установки.
