# Структуры данных

Ref — пять обязательных строк namespace/component/view/type/version. Conan-имя
состоит из первых четырёх полей, версия задаётся отдельно. Например,
soc.mmu.rtl.default/1.0 и soc.mmu.be.lib-lef/4.0. Все поля входят в identity.
View и type — пользовательские строки; SDK не ограничивает их словарь.
Старые name/kind и трёхчастное имя не поддерживаются.

LocalRecord описывает рабочие данные: ref, payload, source, files, nfs.
Source — Path текущего checkout, files — именованные пути упаковываемых файлов,
nfs — именованные абсолютные внешние пути. Flow формирует этот объект до публикации
и передаёт в Graph. Локальный корень не должен извлекаться из Conan.

Record представляет полученный пакет с теми же полями и дополнительным scm —
простым словарём URL/commit. Files уже содержит локальные пути. Source заполняется
по запросу исходников в Ref.get(with_sources=True), до этого равен None.
Физические files/source могут различаться между cache и исключены из сравнения Record.
Метаданные SCM, payload и nfs сохраняют сравнение по содержимому.

У Record нет публичной materialize. Внутренний код получения данных заполняет files
и source до возврата объекта пользователю. У LocalRecord загрузки также нет:
он уже описывает доступные рабочие данные. Классы ресурсов и обёртки путей удалены.

LocalRecord.to_json() подготавливает ref/payload, имена files и абсолютные nfs.
Пути рабочего checkout и исходных файлов в пакет не попадают. SCM фиксирует Conan.
Record.from_json() читает метаданные пакета, сопоставляя имена files путям package_dir.
Record.to_dict() даёт inspection-представление с локальными путями.

Payload — произвольное JSON-значение или пользовательский JSONSerializable с to_json().
При чтении и подготовке публикации он становится независимым immutable-снимком:
объекты — frozendict, массивы — tuple. Классы потребителя не сохраняются; NaN/Infinity
отклоняются. Сериализация payload остаётся ответственностью потребителя.

SearchQuery — точные AND-фильтры всех пяти координат. Dependency(source, target)
не имеет типа и дополнительных свойств. GraphResult содержит локальный корень,
опубликованные зависимости и точные рёбра. to_networkx() создаёт независимый DiGraph
с Ref-ключами и объектами записей в атрибутах.

Ref, Record, LocalRecord, Dependency и GraphResult — frozen dataclass значений.
Catalog и Graph — обычные классы с операциями и контекстом. Graph отвечает за одно
описание проекта и его lockfile; несколько Graph могут работать в одной директории.
