# Архитектурные решения

Проект исследует Conan как каталог аппаратных проектов с точными зависимостями.
Публичная модель отражает возможности этого бэкенда: Record и Dependency.
Конкретные операции dependencies и consumers заменяют общий направленный поиск соседей.
MemoryBackend реализует тот же интерфейс для изолированных тестов.

Представление определяется координатами namespace/name/kind. Чтобы найти LIB/LEF
для заданного RTL, приложение задаёт фильтры кандидатов и проверяет наличие точного
RTL в их графах. Промежуточные узлы могут относиться к любым компонентам.

Версии представлений независимы. Данные опубликованного Ref неизменяемы; повторная
публикация запрещена. Исходящие зависимости сохраняются вместе с новым узлом.
Conan выполняет разрешение своего графа и фиксирует версии/revisions lockfile.
Алгоритм совместимости графового каталога и типизированные рёбра удалены.

Conan CLI выбран из-за экспериментального статуса Python API. Формат рецепта
канонический, без settings/options, overrides и диапазонов. Record сериализуется
в JSON; имя Python-класса пользователя и пользовательские декодеры не хранятся.
Файлы ресурсов остаются внешними.

Root lockfile создаётся до export и хранится внутри рецепта. Чтение явно передаёт
его в Conan; вложенные lockfiles не объединяются при обходе. Recipe revision корня
не включается в собственный lockfile, чтобы избежать самоссылки хеша.
Изменение Python API не меняет существующий формат Conan-рецептов и lockfiles.

Memory выполняет одну операцию под RLock. Conan не предоставляет транзакцию
между поиском remote и загрузками рецептов, поэтому возвращает consistency=live.
Перед публикацией batch полностью проверяется в копии Conan home; удалённые записи
выполняются последовательно. Сбой после начала публикации может быть частичным.

Обратный поиск загружает граф каждого кандидата и не имеет отдельного индекса
обратных связей. Его стоимость, как и копирование home при публикации, существенна
для проверки практичности эксперимента. Пагинация, автоматические повторы, миграции
старых форматов и управление конкурентными издателями не реализованы.
